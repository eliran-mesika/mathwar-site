Math Practice Needs Fewer Worksheets and More Battles

Kids can detect fake fun from across the room. Put arithmetic on a worksheet, add a cartoon star, and somehow everyone involved knows a tiny educational crime has occurred. MathWar is the attempt to make math practice behave like a game first: answer gates, grow the army, survive the wave, and learn because the system keeps moving.

Answers should do something.

In MathWar, arithmetic gates change the run. A good answer can grow the squad. A bad answer can make the next fight worse. That feedback loop is the whole point: math is not a detached quiz floating in space, it is the input that changes the game state.

Short sessions matter.

The target is mobile practice, not a 45-minute homework negotiation. A useful round should be readable, quick, and repeatable enough that a kid can improve without feeling like the app trapped them in a spreadsheet with sound effects.
